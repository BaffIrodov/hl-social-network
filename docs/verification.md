# Проверка проекта

Проверено 3 октября 2026 года на Java 21 (Temurin).

| Проверка | Результат |
|---|---|
| Maven `-Pintegration-test verify` | BUILD SUCCESS; исполняемый Spring Boot JAR собран |
| Модульные тесты | 30 пройдено, ошибок и пропусков нет |
| Интеграционные тесты HTTP + JDBC | 11 пройдено, ошибок и пропусков нет |
| Postman через Newman против собранного JAR | 21 запрос, 37 проверок; ошибок нет |
| JSON, YAML, POM и ссылки `$ref` OpenAPI | Корректны |

Интеграционные тесты проверяют регистрацию, публичную анкету, Argon2id, сохранение хеша
UUID-токена, TTL, истечение сессии, валидацию, SQL-инъекции, откат регистрации,
отсутствие дополнительных индексов приложения и повторный запуск Liquibase.

В среде генерации Docker отсутствовал. Для проверки использовался PostgreSQL 18.3
в PGlite 0.5.8 с TCP-доступом через штатный PostgreSQL JDBC-драйвер.
Для совместимости с этим тестовым сервером задавались `sslmode=disable`,
`preferQueryMode=simple` и размер пула 1. Эти настройки не изменяют конфигурацию проекта.
PGlite и временные инструменты проверки в исходники не входят.

Docker Compose с обычным PostgreSQL 17 здесь не запускался.
Workflow `.github/workflows/ci.yml` настроен на PostgreSQL 17 и Java 21;
его внешний запуск состоится после размещения проекта в GitHub.
Команды повторной проверки на обычном PostgreSQL приведены в README.

## Исправление доверия сертификатам — 7 октября 2026

В Dockerfile добавлен импорт необязательных `docker/certs/*.crt` в доверенное
хранилище JVM стадии сборки перед Maven. TLS-проверка остаётся включённой.
Сертификат для конкретной сети пользователь добавляет самостоятельно.

Проверка на Java 21 с отдельным хранилищем и новым локальным Maven-репозиторием:

- Без CA тестового HTTPS-прокси воспроизведена ошибка `PKIX path building failed`.
- Команды импорта допускают пустую папку и завершаются ошибкой при повреждённом сертификате.
- После добавления CA parent POM Spring Boot 4.1.1 скачан, `mvn validate` завершился успешно.

Тело shell-команды из Dockerfile проверено с подстановкой временных путей и
изолированного хранилища. Сам Docker-образ здесь не собирался: Docker отсутствует.
Исходники приложения, API и миграции этим исправлением не изменялись.

## Два сценария Postman — 12 октября 2026

Текущая коллекция содержит шесть запросов: три в папке «01 — Ручная проверка»
и три в папке «02 — Автоматическая подстановка переменных».
Разделы ошибок и проверки необязательных полей удалены; переменная `minimal_user_id` удалена.

Проверено: структура JSON, число и порядок запросов, отсутствие скриптов у ручных запросов,
отсутствие зависимости ручных запросов от `user_id`/`token`, наличие всех используемых переменных.
Три автоматических запроса и их скрипты точно совпадают с прежним основным сценарием.
JavaScript-скрипты проходят проверку синтаксиса Node.js.
Java-код и настройки БД не изменялись. Повторный HTTP-запуск против приложения
в рамках этого изменения не выполнялся. Показанные выше результаты Newman с 21 запросом
относятся к прежней коллекции до её сокращения.
