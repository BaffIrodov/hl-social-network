# Локальный запуск

Все команды выполняются из корневой папки проекта, где находится `compose.yaml`.

## Запуск в Docker

Установите и запустите Docker с Compose v2.

Соберите и запустите приложение:

```shell
docker compose up --build -d
```

Посмотрите логи:

```shell
docker compose logs -f app
```

Дождитесь сообщения `Started SocialNetworkApplication`.
Приложение доступно по адресу `http://localhost:8880`.

Нажмите Ctrl+C, чтобы выйти из просмотра логов. Приложение продолжит работать.

После завершения проверок остановить приложение можно командой:

```shell
docker compose down
```

Данные сохраняются в volume `postgres-data`.

## Проверка через Postman

Импортируйте файл `postman/social-network.postman_collection.json`.

Откройте коллекцию и на вкладке **Variables** проверьте:
`base_url` должен содержать `http://localhost:8880`.

В коллекции есть два варианта проверки.

### Ручная проверка

Откройте папку **01 — Ручная проверка**.

1. Выполните запрос регистрации и скопируйте `user_id` из ответа.
2. В запросе входа замените значение `id` в Body на полученный ID.
   Выполните вход с тем же паролем, что использовали при регистрации.
3. В запросе получения анкеты замените ID в конце URL на полученный ID.
   Выполните запрос.

В этом разделе переменные автоматически не сохраняются.

### Автоматическая подстановка переменных

Откройте папку **02 — Автоматическая подстановка переменных**.

Выполните запросы по порядку: регистрация → вход → получение анкеты.
Можно также запустить эту папку целиком через Collection Runner.

Полученный ID автоматически сохраняется в переменные коллекции
и подставляется в следующие запросы.

Токен входа тоже сохраняется, но для текущих трёх методов он не требуется.

## Интеграционные тесты

Для запуска тестов на компьютере нужен JDK 21.
PostgreSQL должен работать в Docker.

Один раз создайте отдельную тестовую базу, если её ещё нет:

```shell
docker compose exec db createdb -U postgres social_network_test
```

Запустите тесты.

Linux/macOS:

```shell
./mvnw -Pintegration-test verify
```

Windows PowerShell:

```powershell
.\mvnw.cmd -Pintegration-test verify
```

Успешное выполнение заканчивается сообщением `BUILD SUCCESS`.

Тесты очищают таблицы в базе `social_network_test`.
Основная база `social_network` при этом не затрагивается.

## Подключение к БД

Для подключения к PostgreSQL из клиента БД используйте:

| Параметр     | Значение         |
|--------------|------------------|
| Адрес        | `localhost`      |
| Порт         | `5432`           |
| База         | `social_network` |
| Пользователь | `postgres`       |
| Пароль       | `postgres`       |
